# Autopaspoort

De complete geschiedenis van je auto’s: facturen, onderhoud, APK, plannen en kosten.

Open de app via de link van GitHub Pages van deze repository. Op een iPhone: open hem in Safari, tik op Deel en kies **Zet op beginscherm**. Op een pc: klik in Chrome of Edge op het installeer-icoon in de adresbalk.

- Je gegevens staan alleen op je eigen apparaat, in de browser. Er is geen account en geen server.
- Merk, model, APK en keuringen komen van de open data van de RDW.
- Maak af en toe een back-up via **Meer → Back-up maken**. Daarmee verhuis je je gegevens ook naar een ander apparaat.
